# Provenance

**STATUS: OPEN SOURCE**

This brand identity was designed and generated algorithmically for the OMG project.

- **Concept:** Original 24x24 geometric O-M-G identity, utilizing metadata tagging for publication status on core marks.
- **Vector generation:** Deterministic JavaScript string construction and local filesystem writes; no source artwork, image model, raster embedding, or network request.
- **Raster generation:** macOS `sips-316` rendered target-sized temporary SVG copies for 16, 32, 128, and 512 px marks, and rendered the intrinsic 1200×630 and 1120×640 preview SVGs. The SVG files remain the authoritative sources.
- **Date:** 2026-07-22
- **Authorship:** AI-assisted geometric design generated in this repository under operator direction; no external source artwork or image model.
- **Quality review:** Local XML/static-policy checks plus offline browser and exact-dimension PNG inspection.
