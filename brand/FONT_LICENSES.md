# Font Approach & Licenses

**STATUS: OPEN SOURCE**

To ensure absolute portability and independence from external resources:
- **Primary Wordmark & Core Assets:** The "OMG" wordmark is constructed entirely from raw SVG geometric paths (circles and lines). There are no `<text>` elements in any core marks, wordmarks, lockups, or favicons. They are purely path-based vectors.
- **Previews & Status Strips:** English taglines and visible "OPEN SOURCE" status strips (restricted exclusively to preview SVGs) utilize the generic `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif` CSS font stack. This guarantees safe rendering using the viewer's native system typography without external web fonts.

No proprietary font files are embedded, linked, or required to render this identity.
